# Calculadora no Flowgorithm


**Nome:** Davi Penha Serra Alves


## Objetivo do projeto

A intenção principal e treinar a lógica na criação de algoritmos criando uma calculadora com multiplas funcionalidades utilizando o Flowgorithm. O programa possui um menu com 20 opções diferentes de cálculos e permite que o usuário escolha a operação desejada, informe os dados necessários e visualize o resultado.


## Funcionamento

Ao iniciar o programa, é apresentado um menu com 20 opções de cálculo.

O usuário escolhe a operação desejada digitando o número correspondente. Após realizar o cálculo, o programa retorna ao menu, permitindo a realização de novos cálculos.

A calculadora utiliza uma estrutura de repetição para continuar funcionando até que o usuário escolha a opção **0**, que encerra o programa.


## Funções implementadas

A calculadora possui as seguintes 20 funções:

1. Cálculo do IMC;
2. Cálculo de área de figuras geométricas;
3. Soma;
4. Subtração;
5. Multiplicação;
6. Divisão;
7. Média aritmética;
8. Porcentagem;
9. Regra de três;
10. Conversão de Celsius para Fahrenheit;
11. Conversão de Fahrenheit para Celsius;
12. Cálculo do perímetro de um retângulo;
13. Cálculo do volume de um cubo;
14. Cálculo de juros simples;
15. Cálculo de desconto;
16. Cálculo de velocidade média;
17. Cálculo de consumo de combustível;
18. Identificação de número par ou ímpar;
19. Comparação entre dois números para identificar o maior valor;
20. Cálculo de potência.


## Funções obrigatórias

O projeto contém as duas funções obrigatórias solicitadas pelo cliente(professora):

* **Cálculo do IMC — Índice de Massa Corporal**;
* **Cálculo de área de figuras geométricas**.

Na opção de cálculo de área, são calculadas as áreas de diferentes figuras geométricas.


## Como executar o programa

1. Instale ou abra o programa Flowgorithm;
2. Baixe o arquivo `Projeto_20_cálculos.fprg`;
3. Abra o arquivo utilizando o Flowgorithm;
4. Execute o fluxograma;
5. Escolha uma das opções disponíveis no menu;
6. Informe os valores solicitados;
7. Visualize o resultado do cálculo;
8. Para encerrar a calculadora, digite **0** no menu.


## Estrutura utilizada

O programa utiliza:

* Variáveis para armazenar os dados e resultados;
* Entrada de dados do usuário;
* Saída de dados e resultados;
* Operadores matemáticos;
* Estruturas condicionais para selecionar as operações;
* Estrutura de repetição `While`;
* Comando `Break` para encerrar a execução quando o usuário digita `0`.
